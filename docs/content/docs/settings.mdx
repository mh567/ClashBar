偏好、自启、端口与维护操作集中在「设置」标签。可用 <kbd>⌘,</kbd> 或 <kbd>⌘⌥5</kbd> 直接打开（ClashBar 在前台时）。连接**远程机器**时，部分开关会标明仅作用于本机。

系统代理与 TUN 的使用边界见 [系统代理与 TUN](/docs/network-mode)；完整能力索引见 [功能总览](/docs/features)；快捷键见 [日常使用 · 键盘快捷键](/docs/daily-use#键盘快捷键)。

设置页顶部用 **应用设置 / 内核设置** 两个分区切换。前者只作用于 ClashBar 本身，订阅更新不会影响；后者作用于当前控制的内核，默认完全沿用配置文件，只有你改动过的字段才会被覆盖。

## 应用设置

| 选项 | 说明 |
| --- | --- |
| 开机自启 | 登录 macOS 时启动 ClashBar（需在 `.app` 环境中；可能要求登录项批准） |
| 内核自启 | 应用启动后自动启动 mihomo |
| 状态栏样式 | **图标 + 速度** / **仅图标** / **仅速度** |
| 界面语言 | 简体中文 / English |
| 外观模式 | 跟随系统 / 浅色 / 深色 |
| 直连测试地址 | `DIRECT` 的计算延迟所探测的地址，默认 `http://connect.rom.miui.com/generate_204`；留空时使用该默认值 |

应用设置会直接保存到 ClashBar 本地，无需额外提交，也不会随订阅变化。

### 系统代理绕过

在应用设置中展开 **系统代理绕过**，可维护写入 macOS 系统代理的例外列表：

- 支持主机、域名、CIDR 或 `<local>`。
- 新增、删除和 **恢复默认** 后会直接应用。编辑现有条目时，按回车或离开输入框即可应用。
- 重新开启系统代理时会继续使用已保存列表。

这份列表只在**系统代理开启时**生效，标题右侧会标出「未生效」。使用 TUN 时它不参与任何路由决策，TUN 的排除网段见下方「TUN 排除网段」。

详见 [系统代理与 TUN](/docs/network-mode)。

## 内核设置

**日志级别** 与 **网络** 组里的 **允许局域网**、**IPv6**、**TCP 并发** 改完立即生效，不需要额外操作；**TUN** 开关与协议栈、以及 **代理端口** 改完会留在草稿里，**应用更改** 按钮此时才出现并带待提交数量，也可以 **放弃更改** 清除草稿。关闭面板会保留草稿，切换配置或机器会清除草稿。远程目标下，应用更改会把设置发送到当前远程内核。

网络组里的 TUN 开关和协议栈合并在一行，协议栈胶囊与开关一起靠右。点选协议栈可将其加入草稿，TUN 关闭时也可以预先选择。

每个字段右侧都有来源状态：

- **未覆写**：值来自配置文件中声明的设置，配置文件改动会直接反映到内核。
- **已覆写**：你的设置已提交并通过读回校验，订阅更新后仍保持该值。点击标签可将该字段标为 **待读取**，悬停提示会显示配置文件中的已知值。
- **待提交**：已经改过但还没提交，点 **应用更改** 后生效。
- **未确认**：已提交但没通过读回校验。原记录会保留，可以再次尝试恢复。
- **待读取**：下次应用时会清掉覆写，回到配置文件的值。

已编辑的字段只有通过提交和读回校验后才会成为手动值。应用失败时会保留草稿，可修改后重新提交。端口输入改回当前值时会撤销该端口的草稿。立即生效的字段若提交失败，草稿同样保留，可以再改一次重试。

点击 **应用更改** 时，待应用的分组会分别提交：代理端口一组，TUN 开关与协议栈一组。某一组未通过校验时只回滚这一组，其他组照常生效，失败组的草稿会保留。提示会列出每个失败组及其具体原因；只有确实有组成功时才说明其余更改已应用，全部失败时不会这样表述。

提交过程中顶部模式切换与 TUN 开关会暂时禁用，避免与正在应用的设置互相覆盖。

存在覆写时，可点击顶部的 **全部恢复** 将该字段标为待读取。点击 **应用更改** 后会统一重载配置，并提交草稿中的其他编辑。重载可能短暂中断代理，此时所有字段一次提交，任一字段无效都会阻止本次应用。

运行模式由顶部模式栏切换，内核设置里不再重复提供入口。在内核设置中为模式保存过覆写时，顶部切换不会改动该覆写；读取配置值后，内核重新使用配置文件中的模式。

### TUN 排除网段

网络组底部只读显示 `tun.route-exclude-address`，每个网段独立成标签并自动换行，不会截断。右侧标注来源是内核实际值还是配置文件声明值。它决定哪些网段不进入 TUN 路由表，修改需要编辑配置文件。

它与「系统代理绕过」是两套独立规则：前者管 TUN 路由，后者管 macOS 系统代理的例外列表。

## 系统维护

| 操作 | 说明 |
| --- | --- |
| 清理 FakeIP 缓存 | 请求内核清理 FakeIP 缓存 |
| 清理 DNS 缓存 | 请求内核清理 DNS 缓存 |
| 更新 Geo 数据库 | 内核**运行中**时可更新 GEO 资源 |
| 打开内核目录 | 在访达中打开 `…/clashbar/core` |

面板页脚另提供 **升级 Core**（检查/更新 mihomo）以及应用版本更新提示（若检测到新版本）。

应用更新会先确认，再显示下载进度，安装完成后自动重启；新版本未能启动时会回滚到旧版本，并在下次启动时提示。内核以版本最新者为准：本地已升级到更新版本的内核不会被安装包中的旧内核覆盖，只有安装包内置内核更新时才会替换本地内核。

## 网络与内核联动

- 检测到**网络断开**时，可将内核停止；**网络恢复**后可按策略自动再启动（与内核自启等设置配合）。
- 具体行为以当前版本日志中的「网络断开 / 网络恢复」记录为准。
